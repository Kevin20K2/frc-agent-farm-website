Lesson 1

What Is C++?

Students write, compile, run, edit, and debug a first C++ program before using ESP32 hardware.

Draft video ready

Review the Lesson 1 draft video for pacing, wording, and visual clarity before publishing a final version.

Students practice

  • Explain source code, compiler, program, compile, and run.
  • Identify main, braces, cout, semicolons, comments, and return 0.
  • Compile and run Hello World.
  • Edit printed output and run the program again.
  • Complete a short skill check.

Starter code

#include <iostream>

using namespace std;

int main() {
    cout << "Hello, world!" << endl;
    return 0;
}
