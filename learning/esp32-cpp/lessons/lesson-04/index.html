Lesson 4

Hello ESP32

Students safely connect an ESP32, upload a first sketch, and use Serial Monitor to see setup run once and loop repeat.

Students practice

  • Connect an ESP32 by USB only.
  • Select board and port in Arduino IDE.
  • Upload a safe first sketch.
  • Open Serial Monitor at 115200 baud.
  • Explain setup runs once and loop repeats.

Starter sketch

void setup() {
    Serial.begin(115200);
    delay(1000);

    Serial.println("Hello, ESP32!");
    Serial.println("Setup runs once.");
}

void loop() {
    Serial.println("Loop is running.");
    delay(1000);
}
