Lesson 1: What Is C++?

Welcome to Level 1. Before we touch robot hardware, we need to learn how to give a computer clear instructions.

C++ is a programming language. We write source code, then a compiler translates that code into a program the computer can run.

Source code is what you type. The compiler checks it and translates it. The program is what you run.

This is a complete C++ program. It looks strange at first, but today we only need to recognize the major parts.

Most programming follows a cycle: edit, save, compile, run, and fix. That cycle matters more today than memorizing every detail.
